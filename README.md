# VIRUS Invaders

## Descripción del Proyecto

"Virus Invaders" es un shooter 2D de estilo arcade, inspirado en el clásico "Space Invaders". En este juego, el jugador toma el control de una jeringa que se mueve horizontalmente en la parte inferior de la pantalla. El objetivo es disparar y destruir las oleadas de enemigos, con forma de virus y gérmenes, que descienden desde la parte superior. La partida se desarrolla contra el tiempo, y el jugador busca alcanzar la mayor puntuación posible antes de que el cronómetro llegue a cero.

Este repositorio contiene el proyecto base original desarrollado para la plataforma *PC, así como el porteo completo y adaptado para dispositivos **Android*.
